# Explain It Like I'm Stoned

AI that talks to the brain you have right now.

Not a bit. Not a surfer-bro voice. A real way of communicating for a brain
that's holding less at once, losing the thread, and a little nervous in front
of a wall of text. Which, honestly, is a lot of us at 11pm.

**One idea per message. It re-anchors before every step. It never makes you
feel dumb for asking twice. It stops you before anything you can't undo. And
it writes notes to sober-you.**

## Install

**Claude Code** (two lines, then it's just on):

```
/plugin marketplace add explain-like-im-stoned/explain-like-im-stoned
/plugin install stoned@explain-like-im-stoned
```

**Anything else** — ChatGPT, Claude.ai, Gemini, Cursor, Codex, whatever:
copy one file from [`wrappers/`](wrappers/) into the place your tool takes
instructions. `paste-anywhere.txt` works in any chat box.

## Strains

Say it in plain words. "Sativa mode." "Indica." "I'm too high."

| | |
|---|---|
| **Hybrid** | The default. Everything below. |
| **Sativa** | More ideas, more connections, faster. Brainstorm mode. |
| **Indica** | Slower, shorter, one path instead of three. Wind-down mode. |
| **Too high** | Answers questions. Does nothing irreversible. Tells you to go to bed. |

## The rails

Coding high is fine. Deleting the production database high is not. So before
anything that can't be undone — deleting, sending, spending, publishing,
force-pushing — it stops, says in plain words what's about to happen, and
waits for a real yes. "Sure" and "whatever" don't count.

It also keeps `notes-to-sober-you.md`: what you did, why, what you weren't
sure about, what to check tomorrow. Written for a rested person with coffee
who does not remember tonight.

## The whole thing is one page

[`STONED.md`](STONED.md) is the entire personality. Everything else in this
repo is that page wrapped for a different tool. Read it, change it, send a
pull request. Want a strain that doesn't exist yet? That's a paragraph, not a
project.

## Why

I'm a founder in government affairs. I don't code. I set up my AI to explain
everything to me in plain words, one idea at a time, what a thing *is* before
what it's *called* — and it made me better at my job. Then I noticed the same
setup is exactly what a high brain needs. So here it is.
